# Evidências

Esta pasta armazenará capturas, tabelas e outros registros usados para demonstrar o progresso e os resultados dos testes.

Padrão sugerido para nomes:

```text
AAAA-MM-DD_tipo_descricao.ext
```

Exemplo:

```text
2026-08-29_captura_repositorio-inicial.png
```

Não incluir dados pessoais, credenciais ou informações confidenciais.
