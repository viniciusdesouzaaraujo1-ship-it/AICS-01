# Modelos CAD

Esta pasta receberá modelos e desenhos mecânicos do AICS-01.

Sempre que possível, manter:

- o arquivo editável original;
- uma versão de intercâmbio, como STEP;
- uma imagem de visualização;
- identificação da versão e do software utilizado.

Arquivos muito grandes não devem ser adicionados antes de avaliar o uso do Git LFS.
